# API 需求检查清单: 社区管理模块

本文档用于确认 `013-community-admin` 的需求口径与当前实现保持一致，重点检查契约清晰度，而不是代码实现细节。

## 一、接口边界

- [x] 使用真实前缀 `/community/*`
- [x] 不再使用历史 `/admin/*` 口径
- [x] 工单接口覆盖列表、创建、详情、分派和状态收口
- [x] 志愿者列表、活动、统计接口边界清晰

## 二、权限边界

- [x] 社区管理接口统一受 `auth + adminAuth` 保护
- [x] 社区管理员只能处理所属社区的数据
- [x] 志愿者自服务接口与社区管理接口已分层

## 三、工单状态与协同

- [x] 工单状态值已固定为 `pending`、`assigned`、`processing`、`completed`、`cancelled`
- [x] 后台分派动作与志愿者执行动作职责区分明确
- [x] 后台收口状态仅允许 `cancelled` 与 `completed`

## 四、审计与可解释性

- [x] 工单分派与后台收口具备审计动作
- [x] 志愿者执行动作具备审计动作
