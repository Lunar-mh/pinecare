# Third-Party Services And Authorizations

## Version
- Version: 2026.03-live-defense
- Effective date: 2026-03-12

## Services to document before submission
- DashScope: AI consultation, AI companion, and voice runtime
- WeChat: login and subscribe message APIs
- Aliyun SMS: SOS direct SMS provider
- OSS upload path: family space and voice asset storage
- Medical upstream provider: hospital directory, appointment, consultation, report sync
- Map or location provider: GPS and geofence related capabilities

## Required evidence per service
- Provider name and purpose
- Authorization owner or account source
- Request ID, task ID, message ID, or biz ID in desensitized form
- Latest successful call date
- Latest known failure reason if the service is not healthy
