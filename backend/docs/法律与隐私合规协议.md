# 青松安护 · 法律合规与隐私协议

## 版本信息
- 适用平台：青松安护（PineCare）智慧居家照护平台
- 生效阶段：开源规范版（支持 `stub-ready` 沙盒演示与 `live-ready` 生产切换）

## 隐私政策声明
本项目面向中老年居家健康监测、紧急呼救与社区守护协同。在默认演示或本地沙盒环境（`COMPETITION_SANDBOX`）下，预置数据均为脱敏种子数据或测试数据；系统收集的健康体征档案、用药打卡记录、位置围栏轨迹与亲属绑定关系，仅用于居家健康照护与社区安全响应闭环，不向未授权的第三方商业节点转发。

## 医疗免责声明
平台所提供的血压、心率、血糖等体征趋势展示、阈值告警与慢病用药提醒功能仅用于日常居家健康辅助管理与亲情看护提示，**不构成临床医疗诊断或处方建议**。如遇急症或身体明显不适，请立即拨打 `120` 急救电话或前往正规医疗机构就诊。

## 数据脱敏与最小化合规策略
- **联系方式脱敏**：手机号码、家庭住址及敏感凭证在社区管理后台、志愿者端与运行日志中默认采用遮码脱敏处理（例如：`138****1234`），严禁在控制台或审计日志中明文输出密钥、Token 或完整手机号。
- **位置与求助权限最小化**：实时位置定位（GPS）与安全地理围栏仅在授权监护关系或 SOS/跌倒应急响应流程中展示与触发通知，且所有操作均留存不可篡改的哈希链审计日志。
