# 青松安护（PineCare）— 规范验收清单与部署指南

## 1. 部署与联调准备
请按以下顺序在对应子目录安装依赖并启动四端协同环境。后端推荐使用 `Node 18+`，管理端与小程序编译推荐使用 `Node 20+`。

### 1.1 依赖安装
```bash
cd backend && npm ci
cd frontend && npm ci
cd admin && npm ci
cd volunteer && npm ci
```

### 1.2 基础设施启动
系统依赖 MySQL 8.0 与 Redis 7 支撑持久化数据存储与会话/状态缓存。在仓库根目录一键拉起基础设施与后端：
```bash
docker-compose up -d mysql redis backend
```

### 1.3 数据库迁移与演示种子验证
```bash
cd backend
npm run migrate
npm run smoke:fresh-install
npm run seed:competition:verify -- --dry-run
```

## 2. API 验收基线
- 所有接口统一遵循 HTTP 状态码与业务 JSON 报文外壳 `{ code, message, data }`。
- 成功响应约定：`code: 0`；错误响应由统一错误处理中间件与 `sendControllerError()` 输出对应 HTTP 语义码。
- 双路由兼容挂载：正式前缀 `/api/v1` 与非生产环境根路径 `/` 均保持一致行为。
- 跨域资源共享（CORS）、JWT 双令牌鉴权（Access Token + Refresh Token）、管理员 Redis 会话与接口限流中间件默认启用。
- 第三方能力（微信模板消息、阿里云 SOS 短信、OSS 对象存储）统一采用受控降级模式（`auto / stub / live`），并在管理端运行态诊断界面实时可观测。

## 3. 已知构建说明
- **小程序包体规范**：业务页面全部下沉至 `health`、`medication`、`sos`、`location`、`settings` 五个独立分包，主包体积远低于微信 2MB 红线。
- **后台与志愿者端基线**：默认联调 API 地址为 `http://127.0.0.1:3001`（或 `http://127.0.0.1:3001/api/v1`），启动前请确保端口未被占用。
