🔗 REQUIRED API ENDPOINTS:
═══════════════════════════════════════════════════════════════════════════

The component expects these 3 service functions to be available:

1. sendSmsCode(phone)
   • Input: phone (string)
   • Output: { success: boolean, message?: string }
   • Purpose: Send 6-digit code to phone via SMS
   • Typical endpoint: POST /api/sms/send

2. verifyCode(phone, code)
   • Input: phone (string), code (string)
   • Output: { success: boolean, message?: string }
   • Purpose: Verify the received code
   • Typical endpoint: POST /api/sms/verify

3. resetPassword({ phone, code, password })
   • Input: { phone, code, password } object
   • Output: { success: boolean, message?: string }
   • Purpose: Reset password with verified code
   • Typical endpoint: POST /api/password/reset
