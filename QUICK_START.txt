  - Sends SMS verification code

    * Contains digit

## REQUIRED API ENDPOINTS:

The component expects these services to be implemented:

1. sendSmsCode(phone: string)
   - Sends verification code to phone number
   - Returns: { success: boolean, message?: string }

2. verifyCode(phone: string, code: string)
   - Verifies the code is correct
   - Returns: { success: boolean, message?: string }

3. resetPassword(data: { phone, code, password })
   - Resets password with verified code
   - Returns: { success: boolean, message?: string }

Update the import path in index.tsx if needed:
From: @/services/modules/user
To:   Your actual service location
