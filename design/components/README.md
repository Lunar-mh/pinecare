# 组件规范（components/）

目标：把适老化硬约束落到“可实现、可验收”的组件级规范。

约束来源：
- `design/design-system/MASTER.md`
- `design/tokens/tokens.md`

通用硬约束（所有组件必须满足）：
- 可点击热区：≥44×44px；主操作≥60×60（pt/px等效，条款编号待核验）
- 对比度：目标≥7:1；最低≥4.5:1
- 字号：正文≥20sp、标题≥28sp、数据≥36sp（按场景）
- 单屏≤3个核心操作区（页面层约束，但会影响组件密度）

本目录内每个组件文档至少包含：
- 用途/场景
- 结构（slots/子元素）
- 交互状态（默认/按下/禁用/加载/错误）
- 无障碍（aria-label/可读文本/不只靠颜色）
- 设计约束（引用tokens；不确定标“待核验”）
- 验收清单（可手工验证）
