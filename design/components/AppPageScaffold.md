# AppPageScaffold（页面骨架容器）

## 用途
统一页面的安全区、背景色、默认字号缩放策略（待核验实现方式）、内容区间距与错误/空态挂载点。

## 结构
- Header（可选）：返回/标题/语音按钮
- Body：页面主内容
- Footer（可选）：底部常驻语音栏/TabBar
- States：Loading / Empty / Error

## 设计约束（已核验）
- 背景基色：`#f5f5f0`（见 `design/tokens/tokens.md`）
- 文字主色：`#1a1a1a`
- 对比度：目标≥7:1；最低≥4.5:1
- 单屏信息架构：单屏≤3个核心操作区（页面侧控制）

## 无障碍
- 所有可点击区域满足热区
- 状态切换必须有可读文本（不只靠颜色/图标）

## 验收
- 任一页面在系统字体放大（微信关怀模式，具体倍率待核验）下不出现关键按钮被遮挡/不可点
- 错误/空态可见、可读、可操作（重试按钮热区达标）
