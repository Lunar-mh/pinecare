## 统一规则

- 竞赛阶段只围绕五条主链路推进，不平均扩写所有功能。
- 不允许把 `stub`、设计稿或未接通第三方的能力描述成真实落地成果。
- 不允许随意新增角色、状态和值域，必须同步更新权限矩阵和数据字典。
- 新增页面、接口、任务前，必须先说明服务于哪条主链路。
