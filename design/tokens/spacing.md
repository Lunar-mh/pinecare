# 间距系统（Spacing System）

## 基础间距单位

基于适老化设计原则，所有间距必须保证清晰的视觉层次和足够的留白。

### 基础单位（Base Unit）
- **基础单位**: 8px
- **设计基准**: 375px 设计稿

### 间距层级

| Token | 数值 | 用途 |
|-------|------|------|
| `space.xs` | 8px | 图标与文字间距、紧凑元素间距 |
| `space.sm` | 12px | 小卡片内边距、按钮内边距 |
| `space.md` | 16px | 标准卡片内边距、表单元素间距 |
| `space.lg` | 24px | 大卡片内边距、模块间距 |
| `space.xl` | 32px | 页面区块间距 |
| `space.xxl` | 48px | 大区块分隔 |

### 页面边距
- **页面水平边距**: 16px（移动端安全区域）
- **最大内容宽度**: 100%（小程序满屏设计）

### 组件间距规范

#### 卡片（Card）
- 内边距: 16px
- 圆角: 12px
- 阴影: `0 4px 12px rgba(0,0,0,0.1)`
- 元素间距: 12px

#### 按钮（Button）
- 高度: 52-60px（适老化大尺寸）
- 水平内边距: 24px
- 图标与文字间距: 8px

#### 表单输入（Input）
- 高度: 52px
- 水平内边距: 16px
- 底部边框: 2px solid

### 热区间距
- 相邻可点击元素最小间距: 12px
- 确保手指点击不重叠（基于44×44px热区）

## 响应式适配

小程序环境相对固定，主要适配：
- 字体大小设置（微信字体缩放）
- 安全区域（刘海屏、圆角屏）
