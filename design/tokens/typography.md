# 排版系统（Typography System）

## 字体族

### 中文字体
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Helvetica Neue', Helvetica, Arial, sans-serif;
```

### 字体选择原则
- **优先使用系统字体**：减少包体大小
- **无衬线字体（Sans-serif）**：更适合屏幕阅读（工信部适老化规范要求）
- **避免自定义字体**：小程序环境限制

## 字体大小规范

### 基础层级

| Token | 大小 | 行高 | 字重 | 用途 |
|-------|------|------|------|------|
| `font.display` | 36px | 1.2 | 700 | 数据展示、健康数值 |
| `font.h1` | 28px | 1.3 | 700 | 页面标题、卡片标题 |
| `font.h2` | 24px | 1.4 | 600 | 区块标题 |
| `font.h3` | 20px | 1.5 | 600 | 小标题、按钮文字 |
| `font.body` | 20px | 1.6 | 400 | 正文内容（适老化加大） |
| `font.caption` | 16px | 1.5 | 400 | 辅助文字、时间戳 |

### 适老化强化
- **正文最小**: 20px（不小于此值）
- **标题**: 28px 起
- **数据展示**: 36px
- **行高**: 1.5-1.6，确保阅读舒适度

### 字重（Font Weight）
- **Regular (400)**: 正文、描述
- **Medium (500)**: 次要标题
- **Semibold (600)**: 小标题
- **Bold (700)**: 主标题、重要数据

## 排版原则

### 行长度
- 最佳阅读长度: 25-35个中文字符每行
- 小程序环境: 利用卡片宽度自然控制

### 段落间距
- 段间距: 1.3倍行高
- 段落内首行缩进: 不使用（移动端不适用）

### 文字颜色对比
- 主文字: #1a1a1a（深色）
- 背景: #f5f5f0（米白）
- 对比度: 7:1（WCAG AAA级）

## 特殊场景

### 健康数据展示
- 数值: 36px + Bold
- 单位: 16px + Regular
- 标签: 20px + Regular

### 警告/错误信息
- 颜色: #FF4D4F（警示红）
- 大小: 20px（不小于正文）
- 必须配合图标使用（不只依赖颜色）
