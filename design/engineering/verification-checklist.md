# 验证清单（设计→实现共用）

## 适老化硬约束（已核验）
- 字号：正文≥20sp、标题≥28sp、数据≥36sp（大字报表场景）
- 对比度：目标≥7:1；最低≥4.5:1
- 热区：≥44×44px；主操作按≥60×60执行（条款编号待核验）
- 单屏≤3核心操作区

## 平台约束（已核验）
- 包体：主包≤2MB、分包≤2MB、总≤20MB
- 后台挂起：约5秒

## 手工走查（每个里程碑必做）
- 登录→首页→健康档案→趋势图→返回
- 登录→用药计划→提醒确认→记录
- SOS触发→倒计时→取消/继续→记录
- 家属端：绑定→查看老人状态→定位页

## 失败路径
- 无网络
- 权限拒绝（录音/定位）
- API 4xx/5xx

验收：每条都必须“可见提示 + 可操作下一步”。
