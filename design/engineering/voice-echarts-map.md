# 语音 / 图表 / 地图能力封装（规划）

## 语音
已核验参数（来自产品文档）：
- 唤醒词：银伴银伴
- TTS语速：0.8
- 频段：500-4000Hz（设计参考）

封装目标：
- `services/voice/`：录音授权、识别、TTS播放、失败兜底

验收：
- 权限拒绝/识别失败/播放失败均可走通并有明确提示与替代操作。

## 图表（ECharts）
已核验默认参数：
- `symbolSize: 12`
- `lineWidth: 4`

封装目标：
- `components/elderly/ChartCard`：统一大字号轴/tooltip/图例

验收：
- 手指触控数据点可稳定触发tooltip；不只用颜色区分数据系列。

## 地图
约束（产品文档平台限制章节）：
- 后台挂起与定位持续性受限

封装目标：
- `services/location/`：一次性高精度定位（SOS触发）、轨迹拉取、围栏

验收：
- 无定位权限/弱网场景：提示明确，可重试或改用其它救援路径。
