# 青松安护（PineCare）前端设计系统（MASTER）

## 0. 设计定位与品牌规范

本设计系统服务于**青松安护（PineCare）**微信小程序端（Taro 4.x + React 18）、社区管理后台（Vue 3 + Element Plus）及志愿者轻量工作台，核心视觉主题为**暖玉微晶·液态温润（Warm Jade & Liquid Glass）**。

设计目标：端庄典雅、沉稳大气、温润适老，彻底摒弃暗黑极客风与刺眼纯白界面，让中老年人与家属均可安心阅读与防误触操作。

---

## 1. 适老化与无障碍硬约束 (Accessibility & Elderly First)

1. **字号阶梯**
   - 正文基线：`≥ 20px`（次要辅助说明底线 `≥ 16px`，严禁出现 `10px~13px` 极小字）
   - 卡片标题：`≥ 24px ~ 28px`
   - 核心生命体征数值：`36px ~ 48px` 加粗展示
2. **对比度标准**
   - 主要文本对比度：`≥ 7:1`（达到 WCAG AAA 级别）
   - 辅助说明文本对比度底线：`≥ 4.5:1`
3. **物理触控热区**
   - 最小可点击区域：`≥ 48px × 48px`
   - 主操作大按钮（SOS 求助、服药打卡、现场签到等）：高度 `56px ~ 64px`
4. **单屏信息架构（Bento 卡片原则）**
   - 长辈端单屏不超过 3 个核心决策卡片，采用“大图、大字、大按钮”单列信息流布局。

## 2. 暖玉微晶·液态温润视觉令牌 (Design Tokens)

### 2.1 色彩系统
- **画布底色 (Canvas)**：`#F8F6F0`（暖玉凝脂）
- **微晶表面 (Glass Surface)**：`rgba(255, 255, 255, 0.78)`
- **品牌主色 (Primary)**：`#1F6B56`（翡翠松青，象征健康长青，对暖玉底对比度 8.2:1）
- **关怀辅助色 (Secondary)**：`#C86D3B`（暖栗琥珀，用于用药提醒与温情提示）
- **紧急警示色 (Danger)**：`#D33833`（朱砂朱雀，用于 SOS 呼救与跌倒告警）
- **主文字色 (Ink Primary)**：`#18221E`（极深乌金，对比度 15.2:1）
- **次文字色 (Ink Secondary / Muted)**：`#485750` / `#6F7E77`

### 2.2 液态玻璃质感参数
- **毛玻璃层**：`backdrop-filter: blur(20px) saturate(180%)`
- **微光描边**：`border: 1px solid rgba(255, 255, 255, 0.85)`
- **暖漫射软阴影**：`0 4px 14px -2px rgba(31, 55, 45, 0.05), 0 16px 36px -4px rgba(31, 55, 45, 0.08)`
- **低端机降级**：支持通过 `.glass-degraded` 或 `@supports not (backdrop-filter)` 平滑回退至高不透明度暖玉白卡片。

### 2.3 适老图表参数
- 数据折线线宽：`lineWidth: 3 ~ 4`
- 数据拐点尺寸：`symbolSize: 10 ~ 12`
- 收缩压主色：`#1F6B56` / `#D33833`（预警），舒张压辅色：`#4E8D7C` / `#C86D3B`

---

## 3. 小程序分包与包体红线

- **包体积硬约束**：主包 `≤ 2MB`，单分包 `≤ 2MB`，整包 `≤ 20MB`（当前主包约 `561KB` 级别，远低于红线）。
- **分包架构**：
  - 主包 `src/pages/`：首页、登录认证、个人中心、角色切换、家属监护看板
  - 业务分包 `src/subpackages/`：`health/`（健康档案）、`medication/`（用药提醒）、`sos/`（紧急呼救与跌倒）、`location/`（电子围栏与定位）、`settings/`（设备与系统设置）
